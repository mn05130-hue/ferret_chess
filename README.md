# 심야 게시판

자유게시판에 섞여 올라오는 이상 글을 찾아내는 모바일 호러 게임입니다. 플레이어는 야간 운영자로서 글의 본문과 작성자 기록을 읽고, 의심 표시를 남기거나 글을 삭제합니다.

## 실행

설치나 빌드 없이 브라우저에서 `index.html`을 엽니다. 로컬 서버에서 실행하려면 프로젝트 폴더에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000`을 엽니다.

## 플레이

- 글 제목을 누르면 본문과 작성자의 최근 기록을 볼 수 있습니다.
- 의심 표시는 선택한 글에만 붙습니다. **글 삭제**는 상세 화면에서 열어 본 글 한 건에 적용됩니다.
- 동기화가 끊기면 정상 글도 깨져 보입니다. **복구**를 누르면 화면에 원래 글이 다시 표시됩니다. 정상 상태에서 복구를 누르면 체력을 잃습니다.
- 스토리 모드는 7일간 게시판을 운영합니다. 하루가 끝나는 오전 2시에 삭제 성공, 놓친 글, 오삭제가 공개됩니다.
- 무한 모드에서는 이상 글 한 건을 제한시간 안에 삭제해야 합니다. 오늘의 고정 시드는 같은 날짜에 동일한 시작 시드를 사용하는 무한 모드입니다.

| 판정 | 점수 | 체력 |
| --- | ---: | ---: |
| 이상 글 삭제 | +150 | 변화 없음 |
| 이상 글 놓침 | -100 | -1 |
| 정상 글 삭제 | -75 | -1 |
| 끊기기 전에 동기화 복구 | +100 | 변화 없음 |
| 정상 상태일 때 복구 | 변화 없음 | -1 |

## 코드 구성

- `index.html`, `styles/`: 게시판 목록, 글 상세, 모드 선택 및 결과 화면
- `chat-engine-*.js`: 작성자와 글·기록을 생성하는 기존 엔진. 일반 글과 괴이 문장 데이터는 각각 `chat-engine-dialogue.js`, `chat-engine-anomalies.js`에 있습니다.
- `app-chat.js`, `app-game.js`: 게시글 등록, 화면 표시, 의심 표시 및 글 삭제
- `app-survival.js`, `app-results.js`: 순찰 시계, 삭제 제한시간, 동기화 오류, 결과 판정
- `game-rules.js`: 난이도와 점수 계산
- `assetconfig.js`, `bgmconfig.js`: 결과 화면 이미지와 소리 설정

`?seed=2026`으로 게시글 생성을 재현할 수 있습니다. 스토리 모드에서 `?seed=2026&storyDayMs=5000`을 사용하면 하루를 5초로 줄일 수 있습니다. 게임 중 브라우저 콘솔의 `window.horrorChatGame`으로 상태를 살펴볼 수 있습니다.

## 검증 페이지

로컬 서버에서 `tests/chat-rules-tests.html`과 `tests/app-lifecycle-tests.html`을 열면 점수 규칙과 게시판 흐름을 확인할 수 있습니다.
